Aroha privacy policy

Last updated: 20 November 2026

Who uses Aroha

Aroha is a private assistant used only by its owner (Te Kawa Consultancy Limited, Aotearoa New Zealand). It has no other users.

What Google data Aroha accesses

  • Gmail: reading messages for the owner's briefing and questions; sending email the owner asks for; labelling messages and moving them to Trash when the owner approves. Aroha does not permanently delete email.
  • Google Calendar: reading events, and adding or changing events the owner asks for.

Where the data goes

Aroha's AI model runs on the owner's own computer, and Google data is read and processed there. Google data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

One optional feature, coding jobs the owner starts, uses Anthropic's cloud service; it is not used to send Google data.

The sign-in token is stored on the owner's computer, readable only by the owner's account.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Aroha's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
